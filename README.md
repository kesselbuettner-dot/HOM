# HOM – Hauskosten-Manager

Privates Repository für die Webanwendung **Hauskosten-Manager** auf der UGREEN NASync DXP2800.

Der Quellcode wird beim ersten Import aus einem temporären Archiv übernommen. Die Datenbank und private Rechnungs-PDFs sind nicht Bestandteil dieses Repositories.

## Einrichtung
Nach Abschluss des Imports die Dateien `NAS-README.md`, `compose.yaml`, `Dockerfile` und `.env.example` beachten.
